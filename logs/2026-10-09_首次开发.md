## 用户确认的产品方向

独立于编辑器，直接读取项目文件。按项目、文件、函数框化展示；类和模块以可点击标签浏览。外部编辑器保存后刷新。函数说明读取源码注释，也允许人工填写和审批。首版无需接入编辑器插件、语言服务器或外部 AI。

## 已实现

- Python 3.12 本地 HTTP 服务和浏览器 GUI，仅监听 127.0.0.1。
- Python、R、Java、C、C++、Rust、JavaScript、TypeScript、Go 常用定义与调用提取。
- 文件分组、函数节点、类/模块标签、搜索、语言过滤、上下游聚焦与源码行号。
- 区分静态已解析、候选、未解析关系；不会把任意同名函数连在一起。
- 保存后的目录轮询和图谱刷新；头文件后缀使用同一份解析/监听规则。
- 结构化用途/输入/输出/注意事项；草稿、人工确认、代码变化后待复核。
- SQLite 追加保存历史；项目身份、源码哈希和说明版本检查；导入 AI 文字始终为草稿。
- GUI 自动刷新保留未保存文字；切换项目时草稿按项目隔离。
- 本地虚拟环境、锁定依赖、Windows 启动入口、中文 README 与后续任务记录。

## 发现并修复

- SQLite 事务上下文没有自动关闭连接，导致 Windows 测试临时数据库文件被占用；改为显式关闭。
- 相同源码在不同项目中可能共用函数 ID/哈希，旧页面批注可能写错项目；批注和导入绑定 project_root，并加回归用例。
- `.hh`/`.hxx` 初次可解析却未监听保存；监听复用解析器扩展名和排除目录。
- `tree-sitter 0.26.0` 配合当前 grammar 包解析本工具源码时原生崩溃；降为 0.25.2 后同一用例及完整扫描通过。已增加子进程回归检查，避免将来升级后悄悄复现。
- 首次 GUI 验收脚本没等项目切换完成，也未展开文件列表；修正脚本等待与展开步骤后真实操作通过。

## 边界

- 不是完整编译器或运行时调用跟踪器。继承、多态、宏、重载、动态属性、反射、非标准求值仍可能不完整。
- 精确跨文件导入解析目前重点覆盖 Python；其他语言跨文件同名关系保守标候选。
- 未建立匿名回调的独立节点和顶层脚本执行节点；不会把回调体误算成外层直接调用。
- 输入为 UTF-8/BOM；每文件上限 1 MiB、每项目上限 1500 个支持文件，图一次最多展示 48 个节点。
- `.h` 按 C 解析；C++ 头文件可使用 `.hpp/.hh/.hxx`。文件/函数重命名后的说明自动迁移尚未实现；历史仍保留在数据库。
- 代码版本复核目前采用文件上下文哈希，可能比只看函数体更保守。
- 本轮未实现云同步、自动生成代码、自动删除校验或 AI 正确性裁决。
